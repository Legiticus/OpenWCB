# OpenWCB
Open WCB is an app controlled WebSocket powered device capable of controlling higher voltage motors than typical RC applications in
real time. It is primarily for developers, prototypes and RC enthusiasts who are looking for a easy solution to remotely control higher
voltage components in real time. This is accomplished by using an esp32 connected to multiple high voltage motor controllers while
broadcasting a local network that clients can join to connect with the board and control via a persistent WebSocket connection.
